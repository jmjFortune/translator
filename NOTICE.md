# Upstream attribution

translator was developed from AaronGIG's [pdf2zh-desktop](https://github.com/AaronGIG/pdf2zh-desktop). The retained configuration/glossary compatibility modules and Zotero connector originate from that project; original source remains available there and in the locally retained history.

The current translation engine is [PDFMathTranslate-next](https://github.com/PDFMathTranslate-next/PDFMathTranslate-next), with PDF processing/layout provided by [BabelDOC](https://github.com/funstory-ai/BabelDOC). Installed package metadata identifies both engine packages as AGPL-3.0; their upstream license notices are retained with the bundled distributions.

Other Python/JavaScript libraries, model assets and fonts retain their respective upstream terms. The standalone App includes installed distribution license files and a THIRD_PARTY_PACKAGES.json inventory. This notice records provenance; it does not replace third-party licenses or declare a new project-wide license.
